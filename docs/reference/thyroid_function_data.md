# thyroid_function_data: example dataset for the meddecide module

Example dataset distributed with the meddecide jamovi module for
demonstration and testing.

## Usage

``` r
thyroid_function_data
```

## Format

A data frame with 500 rows and 9 variables:

- patient_id:

  integer variable

- age:

  integer variable

- sex:

  character variable

- tsh:

  numeric variable

- ft4:

  numeric variable

- ft3:

  numeric variable

- anti_tpo:

  numeric variable

- symptom_score:

  integer variable

- thyroid_status:

  character variable
