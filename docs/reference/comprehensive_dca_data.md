# comprehensive_dca_data: example dataset for the meddecide module

Example dataset distributed with the meddecide jamovi module for
demonstration and testing.

## Usage

``` r
comprehensive_dca_data
```

## Format

A data frame with 600 rows and 14 variables:

- id:

  integer variable

- age:

  numeric variable

- gender:

  character variable

- model_excellent:

  numeric variable

- model_good:

  numeric variable

- model_poor:

  numeric variable

- model_miscalibrated:

  numeric variable

- sensitive_test:

  integer variable

- specific_test:

  integer variable

- balanced_test:

  integer variable

- biomarker_high_good:

  numeric variable

- biomarker_low_good:

  numeric variable

- outcome:

  integer variable

- biomarker_high_prob:

  numeric variable
