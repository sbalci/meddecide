# cardiac_data: example dataset for the meddecide module

Example dataset distributed with the meddecide jamovi module for
demonstration and testing.

## Usage

``` r
cardiac_data
```

## Format

A data frame with 500 rows and 11 variables:

- patient_id:

  integer variable

- age:

  numeric variable

- sex:

  factor variable

- hs_troponin_0h:

  numeric variable

- hs_troponin_3h:

  numeric variable

- hs_troponin_6h:

  numeric variable

- delta_troponin:

  numeric variable

- diabetes:

  factor variable

- hypertension:

  factor variable

- smoking:

  factor variable

- mi_status:

  factor variable
