# breast_cancer_data: example dataset for the meddecide module

Example dataset distributed with the meddecide jamovi module for
demonstration and testing.

## Usage

``` r
breast_cancer_data
```

## Format

A data frame with 2000 rows and 10 variables:

- patient_id:

  integer variable

- clinical_exam:

  character variable

- mammography:

  character variable

- ultrasound:

  character variable

- mri:

  character variable

- cancer_status:

  character variable

- age:

  integer variable

- family_history:

  character variable

- brca_mutation:

  character variable

- breast_density:

  character variable
